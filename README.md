## À propos

Portfolio personnel moderne et entièrement responsive, développé avec les meilleures pratiques.

Construit avec : Vite + React 18 + TypeScript + Tailwind CSS + shadcn/ui + Framer Motion
déployé sur : Vercel

Tests unitaires + E2E (Playwright) à plus de 90 % de couverture.

Objectif : présenter mon parcours, mes compétences techniques et mes réalisations de manière claire, élégante et professionnelle.

---

## Fonctionnalités

- **100 % bilingue** Français / Anglais (react-i18next)
- Mode sombre / clair avec persistance (localStorage)
- Animations fluides (Framer Motion)
- Bouton "Retour en haut"
- Téléchargement du CV (PDF)
- Galerie complète du CV avec lightbox
- Formatage automatique du texte en Title Case
- Responsive parfait
- Accessibilité renforcée (ARIA, contrastes, navigation clavier)
- Tests unitaires Jest + React Testing Library (couverture > 90 %)
- Déploiement automatique via Vercel
